마운자로 투약기 스텝퍼 & 근손실 방어 핵심 수칙 4가지

1. 전날 저녁 금식 시 아침 스텝퍼 20분 제한

투약 중 저녁을 거르면 다음 날 아침 혈당이 낮아져 있습니다. 기상 직후 물 300~400ml를 먼저 마신 뒤 15~20분 내외로만 타야 어지럼증을 예방할 수 있습니다.

2. 저녁 스텝퍼는 무조건 21시 이전 종료

24:00 취침을 지키려면 최소 취침 3시간 전(21시 이전)에 운동을 마쳐야 교감신경이 가라앉아 깊은 수면과 지방 분해 호르몬 분비가 원활해집니다.

3. 스텝퍼 전후 5~10분 근력 자극 병행

빠른 감량 시 근손실이 오면 단약 후 요요가 쉽게 옵니다. 스텝퍼 전후로 스쿼트 15회×3세트나 가벼운 덤벨 상체 운동 10분을 꼭 곁들여 주세요.

4. 투약 당일~다음 날은 무리하지 않고 회복

주사 직후 24~48시간은 약물 혈중 농도가 급상승해 울렁거림이나 피로감이 올 수 있습니다. 이때는 고강도 스텝퍼 대신 가벼운 스트레칭과 수분 2L 섭취에 집중하세요.

설치하면 상단 브라우저 주소창 없이 전체 화면 단독 앱처럼 실행됩니다.

iPhone / iPad Safari 브라우저 기준
  1. Safari로 이 페이지 주소에 접속합니다.
  2. 화면 하단 중앙의 공유 버튼(네모 위 화살표)을 누릅니다.
  3. 메뉴를 위로 올려 [홈 화면에 추가]를 선택합니다.
  4. 우측 상단 [추가]를 누르면 바탕화면에 앱 아이콘이 생성됩니다.
갤럭시 / Android Chrome / 삼성 인터넷 기준
  1. Chrome 또는 삼성 인터넷으로 접속합니다.
  2. 우측 상단(또는 하단) 메뉴(⋮ 또는 ≡) 버튼을 누릅니다.
  3. [홈 화면에 추가] 또는 [앱 설치]를 선택합니다.
  4. [설치/추가]를 누르면 전체 화면 앱으로 바로 쓸 수 있습니다.
